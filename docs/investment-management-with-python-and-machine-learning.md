After earning a specialization in [Investment Management with Python and Machine Learning](https://www.coursera.org/account/accomplishments/specialization/WUTZABL42PW8) from EDHEC Business School, I developed an educational platform combining financial expertise with Python programming.

## Technical Implementation

- **Core Technologies**:
  - **Frontend**: [Vue.js](https://vuejs.org/), [VitePress](https://vitepress.dev/), [CodeMirror](https://codemirror.net/)
  - **Backend**: [Pyodide](https://pyodide.org/en/stable/) for [Python](https://www.python.org/) execution
  - **Infrastructure**: Serverless architecture

- **Key Features**:
  - **Python Execution**:
    - Browser-based code running
    - Shared Pyodide instance across editors
    - [Web worker](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API) implementation for non-blocking execution

  - **Editor Capabilities**:
    - Auto-save to [localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)
    - Tab key accessibility support ([CodeMirror docs](https://codemirror.net/examples/tab/))
    - Undo/Redo (`Ctrl+Z`, `Ctrl+Shift+Z`)
    - Real-time code execution

- **Data Visualization**:
  - Interactive financial charts with [Apache ECharts](https://echarts.apache.org/en/index.html)
  - Time series analysis plots
  - Portfolio performance visualization
  - Risk metrics dashboards

  - **Learning Tools**:
    - Interactive notebooks
    - Step-by-step tutorials
    - Code examples & exercises
    - Real market data integration
