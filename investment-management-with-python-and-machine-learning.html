Technical Implementation ​

  • Core Technologies:

    • Frontend: Vue.js, VitePress, CodeMirror
    • Backend: Pyodide for Python execution
    • Infrastructure: Serverless architecture

  • Key Features:

    • Python Execution:

      • Browser-based code running
      • Shared Pyodide instance across editors
      • Web worker implementation for non-blocking execution

    • Editor Capabilities:

      • Auto-save to localStorage
      • Tab key accessibility support (CodeMirror docs)
      • Undo/Redo (Ctrl+Z, Ctrl+Shift+Z)
      • Real-time code execution

  • Data Visualization:

    • Interactive financial charts with Apache ECharts

    • Time series analysis plots

    • Portfolio performance visualization

    • Risk metrics dashboards

    • Learning Tools:

      • Interactive notebooks
      • Step-by-step tutorials
      • Code examples & exercises
      • Real market data integration
